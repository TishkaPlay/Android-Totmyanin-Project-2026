# Clickers — обычный кликер

Простой, но красивый кликер для Android с системой улучшений, статистикой и тёмным градиентным фоном.  
Написан на чистом **Kotlin + Jetpack Compose** без лишних зависимостей.

## 🎮 Функционал

- **Главный экран**  
  — Большая круглая кнопка «КЛИК» (каждое нажатие приносит очки).  
  — Отображение текущего счёта и силы клика.  
  — Три управляющие кнопки (вертикально по центру):  
    *«📊 Статистика»*, *«⬆ Улучшения»*, *«🔄 Сбросить игру»*.

- **Экран статистики**  
  Показывает:  
  — Общее количество кликов за всё время.  
  — Текущие очки.  
  — Силу клика (очков за одно нажатие).  
  — Уровень улучшения.

- **Магазин улучшений**  
  — Позволяет увеличить силу клика на +1 за определённую цену.  
  — Стоимость растёт: 10, 20, 30… очков (формула: `(уровень + 1) * 10`).  
  — Кнопка покупки автоматически блокируется, если не хватает очков.

- **Сброс игры**  
  — При нажатии на кнопку сброса появляется диалог подтверждения.  
  — Полностью обнуляет счёт, силу клика, уровень и общую статистику.

## 🖼️ Визуальное оформление

- Тёмный вертикальный градиентный фон (от `#1A1A2E` до `#16213E`).
- Крупный счёт (64sp) и акцентная оранжевая кнопка клика с тенью.
- Цветные капсульные кнопки действий (синяя, бирюзовая, коричневая).
- Все кнопки имеют скруглённые углы и эффект нажатия (elevation).

## 🛠️ Технологии

- **Язык:** Kotlin  
- **UI:** Jetpack Compose (Material 3)  
- **Управление состоянием:** `ViewModel` + `mutableIntStateOf`  
- **Минимальный SDK:** API 25 (Android 7.1)  
- **Сборка:** Kotlin DSL (`build.gradle.kts`)

## 📱 Как запустить

1. Клонируйте репозиторий или создайте новый проект в Android Studio с шаблоном **Empty Activity**.
2. Замените содержимое файла `MainActivity.kt` на код из этого репозитория (полный листинг прилагается).
3. Убедитесь, что в `build.gradle.kts (Module: app)` добавлена зависимость:
   ```kotlin
   implementation("androidx.lifecycle:lifecycle-viewmodel-compose:2.8.7")
   ```
4. Нажмите Sync Now и запустите приложение на эмуляторе или реальном устройстве.
